# ABTalks Redesign — AI Usage Log

## Project
ABTalks — 60-Day Coding Challenge Platform

## Purpose
This project was redesigned and refined with AI-assisted coding. AI was used for frontend implementation, UI styling, responsive design, debugging, and iterative improvements.

---

## Prompt 1 — Project UI Redesign

I want to redesign the ABTalks frontend into a modern, premium-looking student coding challenge platform.

The design should have:
- Dark purple/black theme
- Modern typography
- Clear navigation
- Student dashboard
- Challenge progress
- Current streak
- Today's challenge
- Responsive layout
- Clean cards and buttons
- Student profile section

Keep the interface professional and suitable for a college student coding platform.

---

Create a student dashboard for ABTalks showing:

- Student name

Use a modern dark purple visual style and make the dashboard work well on desktop and mobile.

## Prompt 4 — Mobile Responsive Design

Make the ABTalks frontend mobile-first and responsive.

On smaller screens:
- Stack cards vertically
- Keep text readable
- Prevent horizontal overflow
- Resize headings appropriately
- Make the student profile fit properly
- Make skill badges wrap correctly
- Keep navigation usable
- Preserve the overall visual design

Use a media query around 650px where appropriate.

---

## Prompt 5 — CSS Debugging

Inspect the CSS structure and fix the missing or incorrectly closed braces without breaking the existing styles.

## Development Workflow

AI assistance was used iteratively during development.

The workflow was:

1. Design the frontend structure.
2. Implement the dashboard and challenge UI.
3. Add the student profile.
4. Improve CSS styling.
5. Debug the CSS/PostCSS issue.
6. Add mobile responsive rules.
7. Test the interface in the browser.
8. Refine the layout based on the rendered result.
9. Commit the completed changes to GitHub.
10. Deploy the project using Vercel.
